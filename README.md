> 모든 작업은 여러분의 컴퓨터 안에서만 끝나고, 코드는 전부 공개되어 있어 누구나 확인할 수 있습니다.

## 왜 만들었나

- 알림장·공지·앨범이 쏟아져서 **준비물을 놓치는 일**이 생긴다
- 앨범은 사진을 **하나하나 눌러서** 받아야 하고, 단체사진 속 우리 애를 찾기 힘들다
- 다른 반 소식까지 섞여서 정말 필요한 정보가 묻힌다

## 기능

메뉴는 딱 세 개입니다.

| 탭 | 하는 일 |
|---|---|
| **챙길 것** | 최근 알림장·공지에서 준비물·복장·당부사항과 날짜를 뽑아 오늘/내일/이번 주로 정리. 체크박스로 챙김 표시 |
| **우리 애 사진** | 우리 아이의 앨범·알림장 사진 중 우리 아이 얼굴이 있는 사진만 골라 ZIP으로 한 번에 받기. 단체사진 포함. 크게 보며 Y/N으로 고치고 다시 찾기 |
| **기준 얼굴** | 6개월 단위로 그 시기 키즈노트 사진 속 얼굴을 골라 등록(사진 파일도 가능), 찾는 기준 조절, 데이터 삭제 |

### 동작 방식

1. 브라우저에 로그인된 키즈노트 웹 세션을 그대로 사용합니다 (비밀번호 입력 없음)
2. 챙길 것은 우리 아이의 **반** 소식만, 사진은 우리 아이에게 온 앨범·알림장만 봅니다 (예전 반·다른 기관 사진 포함)
3. 얼굴을 찾아 눈·코·입 위치로 정렬한 뒤 InsightFace 모델로 비교하고, 반 친구들 전체와 비교한 상대 점수로 판정합니다
4. 애매한 사진은 "확인이 필요해요"에 따로 모아 보여주고, 크게 보며 직접 고를 수 있습니다
5. 고친 내용(맞아요/아니에요)을 배워서 "다시 찾기"로 사진을 다시 받지 않고 재판정합니다

### 개인정보 원칙

- 모든 처리(얼굴 인식 포함)는 **브라우저 안에서만** 실행됩니다 ([Human](https://github.com/vladmandic/human), WebGL)
- 저장하는 것: 우리 아이 기준 얼굴 정보, 체크 상태, 설정 — 모두 이 브라우저의 로컬 저장소에만
- **다른 아이들의 얼굴 정보는 저장하지 않습니다.** 다시 찾기를 위해 사진 탭이 열려 있는 동안만 메모리에 두고, 탭을 닫으면 사라집니다
- 외부 서버 전송, 분석 도구, 광고 없음

## 설치

> 크롬 웹스토어 등록 전까지는 직접 설치 방식입니다.

1. 이 저장소를 내려받습니다 (`Code` → `Download ZIP` 후 압축 해제)
2. 크롬에서 `chrome://extensions` 열기 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택
4. [키즈노트 웹](https://www.kidsnote.com)에 로그인
5. 툴바의 🙂 아이콘 클릭

## 개발

```bash
npm install
npm run vendor   # 얼굴 인식 라이브러리·모델을 extension/vendor 로 복사
npm test         # 준비물 추출·얼굴 판정 규칙 테스트
npm run zip      # 웹스토어 업로드용 zip
```

```
extension/
├── manifest.json
├── background.js      # 아이콘 클릭 → 앱 탭 열기
├── app.html / .css / .js
└── lib/
    ├── api.js         # 키즈노트 웹 내부 API 클라이언트 (요청 간격 제한 포함)
    ├── extract.js     # 준비물·일정 추출 규칙
    ├── face.js        # 얼굴 검출·특징값 (브라우저 내)
    ├── match.js       # 얼굴 판정 규칙
    └── store.js       # chrome.storage.local
```

### 알려진 한계

- 준비물 추출은 **문장 규칙 기반**이라 놓치는 항목이 있을 수 있습니다. 원문을 항상 함께 보여줍니다
- 아이 얼굴은 성인보다 인식률이 낮고, 옆모습·뒷모습·모자 쓴 사진은 놓칠 수 있습니다
- 키즈노트 웹의 비공식 API를 사용하므로, 사이트가 바뀌면 동작하지 않을 수 있습니다
