# 릴스 편집 요청 — 「선우의 어린이집 한 해」

## 만들 것
- 세로 9:16, 25~30초, 자막 중심(내레이션 없음)
- 소재: 「우리애 한눈에」 성장 기록 PDF(선우 만 2세 반) 화면 녹화·캡처, 인쇄본이 있으면 손으로 넘기는 장면
- 음악: 잔잔한 피아노 한 곡 (Pixabay "calm piano" 계열). 처음 2초는 음악만, 끝에서 서서히 줄이기

## 장면 순서

| 시간 | 화면 | 자막 |
|---|---|---|
| 0–3초 | 표지 「선우의 어린이집 한 해」 천천히 확대 | 어린이집 1년 치 알림장, 다시 읽어 보신 적 있나요 |
| 3–9초 | 「처음의 순간들」 페이지. 사진 한 장씩 천천히 | 선생님이 적어 준 "처음"만 모았어요 |
| 9–17초 | 달마다 타임라인을 위로 천천히 스크롤 (3월 → 여름 → 겨울). 선생님 문장 한 줄을 화면 가운데 크게 | (자막 없이 선생님 문장만 크게. PDF 속 실제 문장을 그대로 쓰기) |
| 17–22초 | 원래 알림장(준비물·안내가 섞인 글)에서 공지 문장이 흐려지며 사라지고 이야기 문장만 남는 장면 | 준비물·공지는 빼고, 우리 아이 이야기만 |
| 22–26초 | 마지막 장 "엄마·아빠가 남기는 말" 칸 (인쇄본에 손으로 쓰는 장면이면 더 좋음) | 선생님 글은 한 글자도 고치지 않았어요 |
| 26–30초 | 로고 대신 글자 카드 | 우리애 한눈에 · PC 크롬 무료 / uriae.emilysoft.com |

## 자막 스타일
- 명조 계열(고운바탕 등), 흰 바탕 위 짙은 회색 글자 또는 사진 위 흰 글자 + 옅은 그림자
- 한 화면에 한 줄, 14자 안팎. 느낌표·이모지 쓰지 않기
- 선생님 문장은 따옴표로 감싸고 작은 글씨로 날짜 표시 (예: 4월 28일 · 만 2세 4개월)

## 꼭 지킬 것
- **선우 외 다른 아이 얼굴은 모두 흐리게** (단체사진, 옆자리 친구 포함). 다른 아이 이름이 문장에 있으면 그 문장은 쓰지 않기
- 어린이집 이름, 반 이름, 선생님 이름, 원복 로고가 보이면 가리기
- 키즈노트 로고·앱 화면·"키즈노트 공식" 같은 표현 쓰지 않기 (비공식 도구)
- "AI가 써 준 일기"처럼 보이게 하지 않기. 핵심은 선생님 글을 그대로 모았다는 것
- 휴대폰에서 되는 것처럼 보이게 하지 않기. 끝 카드에 "PC 크롬" 꼭 넣기
- 만든 사람 이야기 없이 브랜드 계정 말투로
