> 🔒 **우리 아이 사진과 정보는 어디로도 보내지 않습니다.**
> 서버 없음 · 회원가입 없음 · 비밀번호 안 받음. 개발자인 저도 여러분의 사진을 볼 수 없습니다.
> 모든 작업은 여러분의 컴퓨터 안에서만 끝나고, 코드는 전부 공개되어 있어 누구나 확인할 수 있습니다.

> ⚠️ 키즈노트(주)와 관련 없는 **비공식** 개인 도구입니다.

## 왜 만들었나

- 알림장·공지·앨범이 쏟아져서 **준비물을 놓치는 일**이 생긴다
- 앨범은 사진을 **하나하나 눌러서** 받아야 하고, 단체사진 속 우리 애를 찾기 힘들다
- 다른 반 소식까지 섞여서 정말 필요한 정보가 묻힌다

## 기능

메뉴는 딱 세 개입니다.

| 탭 | 하는 일 |
|---|---|
| **챙길 것** | 최근 알림장·공지에서 준비물·복장·당부사항과 날짜를 뽑아 오늘/내일/이번 주로 정리. 목록·달력 보기, 체크박스로 챙김 표시, 상관없는 안내·준비물은 "해당 없음"으로 지우기. 그림으로 올라온 가정통신문도 브라우저 안에서 글자를 읽어(OCR) 함께 정리하고, 그림은 카드에 붙여 바로 크게 볼 수 있게 |
| **우리 애 사진** | 우리 아이의 앨범·알림장 사진 중 우리 아이 얼굴이 있는 사진만 골라 ZIP으로 한 번에 받기. 단체사진 포함. 크게 보며 Y/N으로 고치고 다시 찾기. 최근 기간 또는 만 나이 1년 단위로 찾기 |
| **기준 얼굴** | 6개월 단위로 그 시기 키즈노트 사진 속 얼굴을 5개 정도 골라 등록(2개부터 찾기 가능, 사진 파일도 가능), 찾는 기준 조절, 데이터 삭제 |

### 동작 방식

1. 브라우저에 로그인된 키즈노트 웹 세션을 그대로 사용합니다 (비밀번호 입력 없음)
2. 챙길 것은 우리 아이의 **반** 소식만, 사진은 우리 아이에게 온 앨범·알림장만 봅니다 (예전 반·다른 기관 사진 포함)
3. 얼굴을 찾아 눈·코·입 위치로 정렬한 뒤 InsightFace 모델로 비교하고, 반 친구들 전체와 비교한 상대 점수로 판정합니다.
   닮은 친구를 거르려고 "이 얼굴이 앨범 속 가장 닮은 얼굴들(같은 아이의 다른 사진)만큼 기준 얼굴과도 닮았나"를 함께 보고,
   형제자매 기준 얼굴과 더 닮은 얼굴은 빼며, 선생님이 보낸 알림장 독사진을 그 시기의 기준 얼굴로 더합니다
4. 애매한 사진은 "확인이 필요해요"에 따로 모아 보여주고, 크게 보며 직접 고를 수 있습니다
5. 고친 내용(맞아요/아니에요)을 배워서 "다시 찾기"로 사진을 다시 받지 않고 재판정합니다

### 개인정보 원칙

- 모든 처리(얼굴 인식 포함)는 **브라우저 안에서만** 실행됩니다 ([Human](https://github.com/vladmandic/human), WebGL)
- 저장하는 것: 우리 아이 기준 얼굴 정보, 체크 상태, 설정 — 모두 이 브라우저의 로컬 저장소에만
- **다른 아이들의 얼굴 정보는 저장하지 않습니다.** 다시 찾기를 위해 사진 탭이 열려 있는 동안만 메모리에 두고, 탭을 닫으면 사라집니다
- 외부 서버 전송, 분석 도구, 광고 없음

## 개발

```bash
npm install
npm run vendor   # 얼굴 인식 라이브러리·모델을 extension/vendor 로 복사
npm test         # 준비물 추출·얼굴 판정 규칙 테스트
npm run zip      # 웹스토어 업로드용 zip
```

```
extension/
├── manifest.json
├── background.js      # 아이콘 클릭 → 앱 탭 열기
├── app.html / .css / .js
└── lib/
    ├── api.js         # 키즈노트 웹 내부 API 클라이언트 (요청 간격 제한 포함)
    ├── extract.js     # 준비물·일정 추출 규칙
    ├── face.js        # 얼굴 검출·특징값 (브라우저 내)
    ├── match.js       # 얼굴 판정 규칙
    ├── ocr.js         # 그림 안내문 글자 읽기 (tesseract.js, 브라우저 내)
    └── store.js       # chrome.storage.local
```

### 얼굴 인식 측정

확장을 불러온 뒤 `chrome-extension://<확장 ID>/dev/eval.html` 을 열고, 사람마다 폴더 하나에 사진을 넣은 폴더
(예: `측정/민준/*.jpg`)를 고르면 같은 사람/다른 사람 점수 분리, 앱과 같은 판정 결과(맞음·놓침·잘못 찾음),
틀린 사례를 보여줍니다. 사진은 브라우저 안에서만 읽고, 측정 숫자만 기록으로 남깁니다. `dev/` 폴더는 배포 zip에 들어가지 않습니다.

### 알림장 추출 채점

`chrome-extension://<확장 ID>/dev/prep-eval.html` 에서 내 알림장·공지의 추출 결과를 바로잡고 **정답 파일 받기**로
아이 이름을 가린 `prep-cases.json` 을 받아 `tests/private/` 에 두면, `npm test` 가 준비물(맞게 뽑은 비율·빠짐없이 뽑은 비율)과
날짜 정확도를 채점하고 틀린 글을 보여줍니다. `UPDATE_BASELINE=1 npm test` 로 지금 점수를 기준으로 저장하면 이후 점수가 떨어질 때 테스트가 실패합니다.
`tests/private/` 는 실제 알림장이 들어 있어 저장소에 올리지 않습니다.

### 알려진 한계

- 준비물 추출은 **문장 규칙 기반**이라 놓치는 항목이 있을 수 있습니다. 원문을 항상 함께 보여줍니다
- 그림 안내문의 글자 읽기는 꾸밈이 많거나 손글씨인 그림에서 틀리거나 놓칠 수 있습니다. 그래서 안내문 그림을 카드에 항상 붙여 둡니다
- 아이 얼굴은 성인보다 인식률이 낮고, 옆모습·뒷모습·모자 쓴 사진은 놓칠 수 있습니다
- 키즈노트 웹의 비공식 API를 사용하므로, 사이트가 바뀌면 동작하지 않을 수 있습니다
